A deadpan one-star review of sleep, in a single line of 120 characters.
`main.py` writes it to `/output/entry.txt`. The line was chosen from 16
candidates in a criteria-ordered tournament (essential one-star review,
sharpest true grievance, deadpan held, turn in the last words, tight and
specific) and refined over five measured iterations: sleep refuses the
reviewer for three hours every night, then turns up in full, unhurried,
seven minutes before the alarm.
